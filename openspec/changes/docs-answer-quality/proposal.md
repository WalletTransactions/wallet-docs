# Proposal

## Why

Замер 6.3 (`docs-service`, закрыта как известное ограничение): около 14 из 20 вопросов
отвечены верно при пороге 16. Основная потеря — пять ложных отказов «В описании системы
этого нет.» при том, что нужная спека доходит до 8 фрагментов промпта (лучший ранг по вектору
после веса вида — 1): виноват не поиск, а промпт или модель (`gemma-4-e4b` без рассуждения,
≤ 8B Q4 на GTX 1070). Вторая открытая часть — отказ «не по теме» без вызова LLM (4.4): с
`text-embedding-nomic-embed-text-v1.5` расстояния у вопросов по теме (0,163–0,253) и не по
теме (0,231–0,293) пересекаются, порог `kMaxVectorDistance` = 0,5 ничего не отсекает.

## What Changes

- Контрольный набор из 20 вопросов (12 Android, 8 админ) и ожидаемых разделов — в репозитории,
  с запускаемым скриптом замера; сегодня набор нигде не сохранён, цифры не воспроизводятся.
- Подбор причины ложных отказов на этом наборе: промпт (формулировка отказа, порядок и
  оформление фрагментов), число фрагментов `kTop`, режим рассуждения чат-модели
  (`LLM_REASONING_CHAT`), модель из помещающихся в 8 ГБ — по одному изменению за замер.
- Проверка, отделяет ли какой-нибудь сигнал вопросы не по теме до LLM (расстояние первого
  чанка в сочетании с `ts_rank`, разрыв между первым и вторым кандидатом). Реализуется только
  если сигнал разделяет наборы без потери вопросов по теме; иначе вывод записывается в design
  и сценарий «не по теме» в спеке приводится в соответствие с фактом.
- Цель: не менее 16 из 20 верных на контрольном наборе на живой LM Studio.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `docs-answering`: требование «Порог релевантности» (сценарий «Вопрос не по теме» не
  выполняется на настоящих эмбеддингах) и новое требование о контрольном наборе качества.

## Impact

- `wallet-docs`: `src/answer.cpp` (промпт), `src/search.hpp` (`kTop`, при необходимости
  сигнал отказа), `tests/` (разбор и промпт), новый каталог набора и скрипт замера, README
  («Качество ответов»).
- Модель чата или эмбеддингов (если меняется) — настройка LM Studio и `LLM_MODEL` /
  `EMBED_MODEL` в `wallet-infra`; смена модели эмбеддингов требует перезаливки индекса.
- Другие сервисы и клиенты не затронуты: контракт `/api/docs/ask` не меняется.
