- Сверх design: (а) из `simple`-разбора вопроса берутся только лексемы с латиницей или цифрами — иначе «в», «как» совпадали бы почти с каждым чанком, и отказ «этого нет» не наступал бы; (б) в эмбеддинг идут первые 4000 байт чанка (окно nomic в LM Studio — 2048 токенов), в `content` — весь текст; (в) первая неудачная пачка эмбеддингов выключает их до конца заливки, чтобы недоступная LM Studio не стоила таймаута на каждую пачку; (г) база недоступна на вопросе — `503 {"error":"database_unavailable"}` (спека требует только `503`).
- Заливке нужен `Content-Type: application/json`: без него httplib разбирает тело как форму с лимитом 8 КБ и отвечает `413` (записано в README и openapi; важно для `docs-index.sh`).
- Заглушка на `http.server` должна говорить HTTP/1.1: с HTTP/1.0 клиент httplib ждал ≈1 с на каждый ответ (заливка 53 с вместо 1,1 с). LM Studio — HTTP/1.1, к сервису это не относится.
