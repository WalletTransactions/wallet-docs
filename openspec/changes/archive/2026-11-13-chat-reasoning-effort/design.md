# Design

## Context

Причина и замеры — в `proposal.md`. `llm::chat_body(model, system, user)` строит тело `/chat/completions` (`temperature` 0,2, `max_tokens` 1024, без `reasoning_effort`); `llm::HttpOptions` несёт `url`, `model`, `api_key`, `timeout_ms` и общий для чата и эмбеддингов. `cfg.llm_*` читаются в `config.cpp`, клиенты создаются в `main.cpp`. В `wallet-ai` то же решено переменной `LLM_REASONING_CHAT` (по умолчанию `none`, пусто — не передавать).

## Goals / Non-Goals

**Goals:** отвечающий `/api/docs/ask` на моделях с рассуждением; настройка без пересборки; то же имя переменной, что у `wallet-ai`.

**Non-Goals:** смена модели ответа; проверка допустимых значений `reasoning_effort`; увеличение `max_tokens`; изменение таймаута гейтвея; чтение `reasoning_content`.

## Decisions

**1. Имя `LLM_REASONING_CHAT`, умолчание `none`.** Совпадает с `wallet-ai`, один и тот же LM Studio обслуживает оба сервиса, значения одни. Умолчание `none` — безопасное для справочного сервиса: ответ по фрагментам не требует рассуждений, а запрос без параметра на gemma-4 стоит 12 с и пустого ответа. Альтернатива «пусто по умолчанию» отвергнута: ломает test и prod без новой настройки.

**2. Значение не проверяется.** Допустимые значения определяет сервер модели (`none`, `low`, `medium`, `high` и расширения). Сервис передаёт строку как есть: новое значение не требует релиза. Ошибочное значение сервер вернёт как `4xx`, что уже логируется как `llm_failed` (`http_<код>`).

**3. Отключение — значением `off`.** `process_env()` (и тестовый `Lookup`) сводят пустую строку к «не задано», поэтому различить «не задана» и «пусто» нельзя. `config.cpp`: нет значения — `none`, `off` — поле не передаётся (в `Config` хранится пустая строка), остальное — как есть. Так сервер, не знающий параметра (не LM Studio), отключается одной строкой в env.

**4. Параметр только у чата.** `HttpOptions` получает поле `reasoning_effort`; `chat_body` принимает его аргументом и добавляет поле только если оно не пусто; `embeddings_body` не меняется. Эмбеддер получает `HttpOptions` с пустым значением.

**5. Таймаут гейтвея не трогаем.** Замер 1,8 с при `none` на малом примере; на 8 фрагментах ожидаются единицы секунд. Если после выката ответ превысит 30 с, это отдельная задача (дешёвая модель или таймаут гейтвея).

## Risks / Trade-offs

- [Модель без поддержки параметра отвечает `400`] → `LLM_REASONING_CHAT=off` отключает передачу; LM Studio для gemma-4 принимает `none`.
- [Качество ответа без рассуждения ниже] → задача справки: пересказ фрагментов с номерами `[n]`; проверяется ручным вопросом на test.
