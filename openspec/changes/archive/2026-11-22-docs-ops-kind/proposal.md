# Proposal

## Why

Справка `wallet-docs` строится только из OpenSpec (`spec`, `change`, `archive`), поэтому знание, которое живёт в README, — переключатели развёртывания, таблицы переменных, порядок выкатки, устройство mTLS и процедуры, — для `ask_docs` невидимо. Положить такие файлы в тот же индекс как есть нельзя: у них нет вида в таблице области, а в них лежат внутренности контура (пути секретов, схема сетей), которые обычным пользователям приложения показывать не нужно. Нужен отдельный вид документов, закрытый ролью `admin`.

## What Changes

- Новый вид чанков `ops` — справка по развёртыванию и эксплуатации.
- В `ops` попадают только файлы с именем `README.md` на любой глубине репозитория (корень, `infra/env/README.md` и т. д.). Планы `org/docs/TODO_*.md` и прочие `.md` вне `openspec/` не индексируются. Вендорные и служебные каталоги (`third_party/`, `node_modules/`, `.worktrees/`, `build/`) пропускаются.
- `ops` видит только `role` = `admin`. Остальные области (`android`, `web`, `mcp`, `telegram`) не меняются, токен без `role` не получает `ops` ни при каком `platform`.
- Разбор пути: `capability` для `ops` — каталог файла (корневой README — `README`, `infra/env/README.md` — `infra/env`).
- Миграция БД расширяет `CHECK` на колонке `kind` значением `ops`; прежние миграции не правятся.
- Метка вида в промпте ответа — «справка по развёртыванию (README, может отставать от спек)»; вес вида в слиянии рангов — как у `change` и `archive`.
- `openapi.yaml` и `README.md` сервиса описывают новый вид.
- Заливка: выбор файлов на стороне Jenkins (`wallet-infra/infra/env/docs-index.sh`) сейчас отдаёт только `openspec/**/*.md`; его правка — отдельный change в wallet-infra (см. design).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `docs-indexing`: правила видов и «посторонних файлов» — добавляется вид `ops` и пути `README.md`; чанкинг прочих `.md` не меняется.
- `docs-answering`: область документации — вид `ops` только у `role` = `admin`; метка вида в промпте.

## Impact

- **wallet-docs**: `src/chunking.cpp` (`classify_path`), `src/access.cpp` (`scope_for`), `src/answer.cpp` (метка), `src/search.cpp` (вес), миграция `migrations/000002_*`, тесты, `openapi.yaml`, `README.md`, `VERSION`.
- **wallet-infra** (отдельным change): `infra/env/docs-index.sh` — отбор файлов для заливки; без него вид `ops` в индексе останется пустым.
- **Данные**: чанки `ops` добавятся при следующей заливке; индекс воспроизводим, бэкап не нужен. Откат — удаление чанков `ops` и возврат прежнего `CHECK`.
- **Безопасность**: README могут содержать внутренние детали; доступ только админу, секретов в README быть не должно (значения вроде токенов не хранятся в файлах репозитория).
