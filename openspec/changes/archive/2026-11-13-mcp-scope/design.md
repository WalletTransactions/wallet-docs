# Design

## Context

`scope_for(role, platform)` (design D5 `docs-service`) — константа в коде: `admin` видит
всё, `android` — `android-wallet`, `web` — `wallet-web` и `wallet-web-eqdefault`, иное —
пусто. Ошибка в таблице не должна открыть чужие спеки, поэтому она не настройка. Токены,
которые приходят от wallet-mcp, роли не несут: JWT по `wmcp_…` имеет `platform` = `mcp`,
JWT обмена наследует `platform` исходной сессии. См. proposal.md.

## Goals / Non-Goals

**Goals:**
- Клиент MCP с персональным токеном получает справку по тому, что видит web-пользователь,
  и по самому wallet-mcp.
- Никто с токеном MCP не видит `change`/`archive` и бэкенд-репозитории.

**Non-Goals:**
- Новые claim'ы, новая роль, конфигурируемая таблица.
- Правка поиска, промпта и порогов (качество — задача 6.3 `docs-service`).

## Decisions

**D1. Область `mcp` = web + `wallet-mcp`, только `spec`.** По ответу владельца: MCP-клиент
видит то же, что web-пользователь, плюс описание самих инструментов MCP, чтобы справка
отвечала про `ask_docs`, `balance` и остальные. Альтернативы «только wallet-mcp» и «как
Android + web» отвергнуты как слишком узкая и слишком широкая; «как админ» — как раскрытие
внутренностей любому, кто выпустил MCP-токен.

**D2. Роль не нужна, а её отсутствие — не админ.** Проверка `role == "admin"` остаётся
первой строкой: токен без `role` до неё не доходит, `platform` = `mcp` даёт ровно область
D1, даже если пользователь — администратор (как в `google-auth/mcp-tokens`: «JWT обмена
без роли»).

**D3. Строка `mcp` — в коде.** Тест таблицы расширяется строкой `mcp` и токеном без
`role`; новая платформа в будущем — правка кода и выкат (design D5 `docs-service`).

**D4. Индекс `wallet-mcp` — зависимость выкатки.** Область без проиндексированного
репозитория вернёт только web; проверяется отдельной задачей.

**Правки в других сервисах:** google-auth (`docs-mcp-audience`), wallet-mcp (`docs-tool`),
wallet-infra — только проверка списка индекса. Гейтвей не меняется: wallet-mcp ходит в
wallet-docs напрямую.

## Risks / Trade-offs

- **Область шире, чем у Android.** MCP видит web-спеки, Android — нет; для владельца это
  осознанный выбор. Риск — расхождение с ожиданиями при добавлении клиентов; закрывается
  тестом таблицы.
- **Порядок архивации.** Дельта изменяет требование, которого нет в основных спеках до
  архивации `docs-service`; поэтому `mcp-scope` архивируется строго после.
