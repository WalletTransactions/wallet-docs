# Proposal

## Why

Пользователи Android и web (и админ, которому нужна вся система) хотят спрашивать «как это
работает» и получать ответ по описанию, которое уже ведётся в OpenSpec-спеках 11
репозиториев (~4,4 МБ markdown). Поиск по такому объёму grep'ом плохо отвечает на вопросы
своими словами, а читать спеки руками неудобно. Нужен отдельный необязательный сервис,
который индексирует спеки и отвечает по ним, не связывая себя с остальными сервисами.

## What Changes

- Новый C++-сервис `wallet-docs` (порт 8089), новый репозиторий.
- `PUT /docs/index/{repo}` — Jenkins заливает файлы `openspec/**/*.md` репозитория; сервис
  режет их по структуре спеки (одно требование со сценариями — один чанк), считает
  эмбеддинги в LM Studio и атомарно заменяет чанки этого репозитория.
- `GET /api/docs/status` и `POST /api/docs/ask` (через гейтвей): проверка токена, область
  документации по `role` и `platform`, гибридный поиск (полнотекст + вектор) с фильтром в
  SQL, ответ от LLM по найденным чанкам с указанием источников.
- Область: админ — все репозитории и виды файлов; пользователь Android — только
  `android-wallet`, спеки; пользователь web — только `wallet-web` и `wallet-web-eqdefault`,
  спеки; остальные — отказ.
- Своя база (`DOCS_POSTGRES_DB`) с таблицей `doc_chunks` и расширением `vector`.
- Ограничение частоты вопросов на пользователя, чтобы не занимать единственный GPU.
- Каркас: `/healthz`, `/version`, `/metrics`, `/openapi.yaml`, `/docs`.

## Capabilities

### New Capabilities
- `docs-indexing`: приём и разбор markdown-файлов репозитория, чанкинг, эмбеддинги, атомарная замена индекса репозитория.
- `docs-answering`: статус, вопрос-ответ, область документации по токену, гибридный поиск, ограничения и ошибки.
- `docs-service-ops`: конфигурация, запуск без обязательных зависимостей, служебные ручки.

## Impact

- **wallet-docs** (новый репозиторий): исходники, `migrations/`, `openapi.yaml`, Containerfile, CI-сборка образа в ghcr.
- **Другие сервисы**: google-auth (`docs-audience`: `aud`/`scope` токена), wallet-gateway
  (`docs-route`), wallet-infra (`wallet-docs-assistant`: pgvector, профиль `docs`;
  `docs-index-upload`: заливка из Jenkins), android-wallet и wallet-web (`docs-assistant`).
- **Хост**: LM Studio получает ещё одну модель (эмбеддинги); она должна помещаться на GPU
  рядом с чат-моделью.
